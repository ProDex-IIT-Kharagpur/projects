Introduction-
This project is a simple automatic solar tracker built using an Arduino, LDR sensors, and a servo motor. The sensors detect differences in light intensity, and the Arduino moves the servo to turn the panel toward stronger light. The system is simulated in Tinkercad to show how it responds when the light changes.

Applications-
Solar tracking can help solar panels receive more sunlight throughout the day. This idea can be used in solar-powered chargers, irrigation systems, and small off-grid power setups. The project also helps us understand how sensors and motors work together to automatically respond to changes in the surroundings.
